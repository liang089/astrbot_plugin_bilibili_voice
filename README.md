# astrbot_plugin_bilibili_voice



注意:本插件采用deepseek编写，可能会出现离奇的兼容性问题



#### 第一:本插件意旨在解决什么需求

本插件通过B站搜索，用途为让用户搜索B站视频/直接通过BV号或分型链接下载等方式将B站视频转码为mp3文件发布在QQ聊天上，所以非常适合在群里彰显您的伟大的审美

#### 

#### 第二:插件如何安装

本插件支持从astrbot插件商店一键安装

##### 第三其一:如何登录哔哩哔哩

###### 

###### 警示

我们非常不希望您使用您自己使用的哔哩哔哩账户登录，因为这可能导致封号我们更希望您可以找一个小号，如果您没有第二个手机号，我们还有解码平台可供选择

建议解码平台https://lubansms.com/（哔哩哔哩国内每号0.43美刀）（这不是您的唯一选择）

###### 

###### 正文

打开本插件的UI然后你会看见一个二维码，打开哔哩哔哩，扫个码，完成

##### 

##### 第三其二:指令使用教程

1:bili\_login 获取 Bilibili 扫码登录二维码。

2:bili\_refresh 刷新二维码。

3:bili\_status 查看 Bilibili 登录状态

4:bili\_search 搜索 Bilibili 视频:/bili\_search 关键词

5:bili\_down 下载搜索结果或链接并转成 QQ 语音:/bili\_down 1 或 /bili\_down BV...
